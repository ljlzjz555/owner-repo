# Brief Intake

Use this reference when building an ecommerce image generation intake form, SOP, or production handoff.

## Minimum Brief

Capture these fields:

| Field | Purpose |
| --- | --- |
| Product name and SKU | Anchors prompts to a specific sellable item. |
| Category | Determines marketplace norms and buyer expectations. |
| Source assets | Product photos, packaging files, brand guide, logo, PDP, or SKU sheet. |
| Key differentiators | Converts product strategy into feature images. |
| Required channels | Controls dimensions, text density, and content restrictions. |
| Audience | Helps choose lifestyle context, model, props, and messaging. |
| Offer | Supports ad and promo variants without inventing discounts. |
| Must show | Prevents omissions such as ports, texture, ingredients, bundle items, or scale. |
| Must avoid | Captures banned claims, competitor references, unsafe use cases, and brand exclusions. |
| Locale and language | Controls copy, reading direction, cultural references, and currency. |
| Deliverables | Defines count, aspect ratios, format, naming, and deadlines. |

## Useful Questions

Ask only the questions that change production decisions:

- What product photo or page should be treated as the ground truth?
- Which channel is first priority: marketplace listing, paid social, storefront, email, or short-video thumbnail?
- Are we allowed to include text in the image, and is the copy already approved?
- Should the output be photorealistic, premium editorial, clean marketplace, UGC-style, or graphic ad creative?
- Which details must remain exact: color, label, shape, material, model, packaging, or accessories?
- Are there regulatory, trademark, model, children, health, finance, or safety constraints?
