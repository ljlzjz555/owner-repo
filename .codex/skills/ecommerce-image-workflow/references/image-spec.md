# Image Spec

Use this reference for detailed ecommerce shot planning, prompt writing, and review.

## Shot Types

| Shot | Job | Notes |
| --- | --- | --- |
| Hero | Identify the product quickly. | Keep product large, clean, and unobstructed. |
| Feature | Explain one benefit. | Pair a visual cue with short approved copy when text is allowed. |
| Detail | Prove material, texture, mechanism, ingredients, or included parts. | Use macro framing or callouts without distorting the product. |
| Lifestyle | Show use context and target buyer fit. | Keep the product inspectable; avoid unrealistic use. |
| Scale | Show size, fit, quantity, or pack contents. | Use familiar props or model context only when accurate. |
| Comparison | Help shoppers choose. | Use neutral wording unless claims are approved. |
| Offer | Support promo or bundle conversion. | Do not invent price, discount, scarcity, or guarantees. |
| Retargeting | Remind and reduce friction. | Reuse recognizable product angle with a sharper hook. |

## Prompt Construction

Write prompts in layers:

1. Product fidelity: exact visible product facts and source-image constraints.
2. Commercial job: what the image should make the shopper understand.
3. Composition: crop, angle, safe area, product size, background, props.
4. Lighting and rendering: realism, shadows, reflections, color temperature.
5. Brand and channel style: clean marketplace, premium editorial, UGC, holiday, storefront, or paid social.
6. Text rules: no text, approved text only, or reserved copy space.
7. Avoidance: wrong variants, extra logos, fake badges, distorted packaging, unsupported claims.

## Product Fidelity Rules

- Treat user-provided product photos, packaging, labels, and SKU data as higher priority than style examples.
- Avoid changing core product geometry, logo placement, label hierarchy, colorway, included accessories, or quantity.
- If exact label text matters, recommend placing text in design software after generation unless the image model can reliably preserve typography.
- For bundles, list every included item and quantity.
- For apparel, specify fit, fabric behavior, model constraints, and visible size cues.
- For food, beauty, health, baby, finance, and electronics, avoid unsupported safety, medical, performance, or certification claims.

## QA Checklist

Use this checklist before handing off assets or prompts:

| Check | Pass condition |
| --- | --- |
| Product match | Shape, color, label, material, and accessories match the source. |
| Channel fit | Aspect ratio, safe area, background, and text density match destination. |
| Claim safety | No invented awards, certifications, discounts, guarantees, or regulated claims. |
| Readability | Any approved text is spelled correctly and legible at thumbnail size. |
| Composition | Product is dominant and not blocked, warped, or cropped awkwardly. |
| Consistency | Batch variants keep SKU identity stable across scenes. |
| Export | File type, dimensions, naming, and folder grouping match the brief. |
